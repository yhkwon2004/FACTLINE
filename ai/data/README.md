## 법률 원문

국가법령정보센터에서 학교폭력예방법과 시행령, 형법·민법·개인정보 보호법·근로기준법·근로자퇴직급여 보장법·스토킹처벌법·정보통신망법·통신비밀보호법·성폭력처벌법을 선정했습니다. 판례는 학교폭력 처분·집행정지, 사기·손해배상·협박·상해 등의 선별 원문 7건입니다. 본문·수집일·출처 URL·해시는 각 항목에서 확인할 수 있습니다. 저장한 스냅샷을 검색하므로 사건 당시 유효한 조문·부칙·판결은 운영 시 공식 출처와 대조해야 합니다. [출처 목록](sources.json)

## 평가와 권리

합성 분류기는 같은 도메인의 작은 문형 집합에서 평가했습니다. 동명이인의 신원, 실제 사건 발생 여부, 법적 책임을 검증한 수치는 없습니다. 사용자에게서 받은 원본·비공개 상담·관계도 참고 이미지로 모델을 학습하지 않습니다. 제품용 합성 시연 문장 4개와 학습 자료는 용도가 다릅니다. [실제 시연](../../public/demo/scenario.json)

KLUE RE는 Sungjoon Park 등(2021)의 한국어 언어 이해 벤치마크입니다. 공식 판본의 주체·대상·관계로 학습용 문답을 구성한 항목에는 원본 GUID를 기록합니다. 공개 법령·판결문 출처와 공개 모델·파생 자료의 조건은 별도로 기록합니다.
