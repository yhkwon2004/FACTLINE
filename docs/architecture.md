# 이음로그 데이터 흐름

기본 모드에서 새 기록의 원본 저장과 분석 동의는 브라우저가 담당합니다. 배포 웹은 계정 인증 및 승인된 텍스트의 분석 요청을 처리합니다. [제품 도식과 시연](../README.md)

| 작업 | 처리 위치 | 구현 |
|---|---|---|
| 가입·로그인 | Google Identity Services → 웹 서버 | Google ID 토큰의 서명·issuer·audience·만료·nonce·이메일 검증 여부를 확인합니다. 서버는 이메일과 Google 계정 식별자에서 서로 다른 용도의 HMAC 검색 키를 만듭니다. 원문 이메일과 계정 식별자는 로그인 시 일시적으로 처리합니다. |
| 원본 저장 | 브라우저 IndexedDB | `DeviceVault.ts`는 보관함 암호·salt로 AES-GCM 키를 유도합니다. 파일·문서마다 새 IV를 사용하고 레코드 식별자를 추가 인증 데이터에 묶습니다. 문서의 revision을 비교한 후 저장합니다. |
| 전사·OCR | 브라우저 | `browser-media.ts`와 음성 전용 Worker에서 공개 모델을 실행합니다. 모델 파일을 내려받을 때 외부 서비스에 네트워크 접속 정보가 남을 수 있습니다. 음성·사진 자체는 기기에서 처리합니다. |
| 익명 검토 | 브라우저 → 승인 요청 | `PrivateData.ts`가 이름 후보와 지정한 민감 표현을 치환하고 원문 위치를 추적합니다. 사용자에게 본문·질문·기준일을 보여줍니다. `/api/private/analyze`는 세션·동의·허용 필드·길이·내용 요약값을 검사하며 남아 있는 식별번호 등을 거부합니다. 문맥상 식별 가능성은 사용자가 검토해야 합니다. |
| 관계·질의·법률 | 연결 PC, 결과는 브라우저로 반환 | Kiwi·다국어 E5·Ridge와 문법 규칙으로 원문 근거를 추출합니다. Qwen3-1.7B LoRA는 일반 질문에 사용합니다. 법률 관련 키워드가 있는 질문은 원문 검색과 확인 질문 경로로 보냅니다. 새 요청과 응답을 앱 저장소에 남기지 않습니다. |
| 관계도·타임라인 | 브라우저 | 원문을 다시 대조해 근거와 표시할 이름을 복원하고 동일 브라우저의 열린 탭에 변경 버전을 알립니다. 사용자가 확인한 문장만 시간순 기록에 들어갑니다. |
| 전달 | 송신자 기기 → 사용자 선택 채널 → 수신자 기기 | 선택한 자료의 원문 텍스트를 별도 256비트 난수 토큰으로 암호화한 파일을 만듭니다. 별도 전달한 토큰과 파일을 수신 화면에서 열 수 있습니다. 서버 중계, 만료, 전달 후 회수는 지원하지 않습니다. |

## 화면과 검토 흐름

모바일 수첩과 웹 작업대는 같은 암호화 보관함·분석 결과를 읽으며 사용자의 녹음·검토 동선에 맞게 진입 화면을 나눕니다. `workspace-surface.ts`는 직접 고른 화면을 먼저 적용하고, 선택이 없을 때 브라우저의 모바일 기기 신호를 사용합니다. 공개 시연은 주소의 `view=mobile` 또는 `view=desktop`으로 두 화면을 명시해 재현할 수 있습니다.

### 인물·시점·사건 색인

`indexCase`는 원문과 일치하는 후보 및 사용자가 확인한 진술을 모아 세 축에 해당하는 인덱스 세 개로 각 연결을 나타냅니다. 조합이 생긴 곳만 저장하고 화면에서 고른 인물·시점·사건을 모두 만족하는 진술만 조회합니다. 누락 필터는 시점·상대방·금액·원문 위치 등 원문 근거를 재확인할 항목을 보여줍니다. 이전 버전을 사용하면 이를 표시하고, 중복 인용으로 위치를 특정할 수 없는 경우 임의의 위치를 강조하지 않습니다. 필터가 가리키는 빈칸은 해당 자료에 근거가 없다는 의미입니다. [색인과 원문 대조](../src/domain/services/CaseIndex.ts)

### 기존 계정의 서버 자료 가져오기

이전 버전의 원본이 있는 계정은 자신의 파일 목록을 받아 기기에 가져올 수 있습니다. 원본을 복호화해 해시를 비교하고 로컬 사본을 검증한 뒤, 별도로 동의한 경우에만 서버 사본 삭제 요청을 보냅니다. 새 모드는 이전 사건·일상 기록·통합 가져오기 API의 쓰기를 차단합니다. 새 기기에서 로그인하면 같은 원본이 자동으로 보이는 구조가 아니므로 기기 간 이동에는 암호화 백업이 필요합니다.

Vercel의 비공개 Blob 구성은 계정·운영 상태와 구버전 사본에 사용합니다. 연결 PC를 끄면 새 익명 본문 분석은 사용할 수 없습니다. 보관함 열기, 기기에 저장한 기록 보기, 공개 시연은 분석기 가용성과 독립적입니다.
