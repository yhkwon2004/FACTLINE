# 관계도 정밀 구현 설계

2026-11-19 · **개발 설계이며 아래 고도화가 모두 구현된 상태는 아닙니다.** 현재 가능한 편집과 실제 학습 수치는 [README](../README.md), 실행 증거는 [검증 기록](verification.md)에 있습니다.

## 목표와 경계

뉴스 인물 관계도처럼 인물·행위·금액·설명을 명확히 연결하면서 드로잉 도구처럼 배치와 선을 수정합니다. 화면 편집은 원문이나 AI의 근거를 바꾸지 않습니다. 원문에서 추출한 진술, 사용자가 확인한 기록, 직접 그린 도형을 구분합니다. AI의 확신도를 유죄·진실·법적 증거능력으로 표현하지 않습니다.

기존 Next.js·SVG·암호화 저장·브라우저 배치 모델을 확장합니다. 새로운 그래프 서버나 협업 프레임워크를 도입하기 전에 아래 검증 사례로 현재 구현의 한계를 해결합니다.

## 근거와 그림을 분리한 데이터

~~~mermaid
flowchart LR
 S[원본 해시 / 추출 버전] --> M[언급 + 정확한 원문 범위]
 M --> A[진술: 행위자 / 행위 / 대상 / 부인]
 M --> E[실체 UUID / 별칭 / 미확인 신원]
 A --> P[그림 노드 / 포트 / 선 / 라벨]
 E --> P
 U[사용자 직접 작성] --> P
~~~

- **원본**: evidenceId, 원본 SHA-256, 정규화 방식과 추출 버전, 추출 텍스트 해시를 보관합니다. 기존 원본은 수정하지 않습니다.
- **언급**: sourceVersionId와 UTF-16 start/end를 보관합니다. 서버에서 text.slice(start,end)와 quote의 완전 일치를 검증합니다. 한글 조합·이모지를 포함한 검사를 둡니다. 음성 범위는 근사 전사 시각이며 발화자 신원 확정이 아닙니다.
- **실체**: 영구 UUID를 사용합니다. 이름은 표시 속성이고 동일 인물의 증명이 아닙니다. 같은 이름 후보는 사용자가 병합·분리할 수 있게 하며 각 언급의 출처를 유지합니다.
- **진술**: assertionId, mentionIds, actorEntityId, targetEntityId, action, polarity, eventTime, amount, modelVersion을 분리합니다. 서로 반대되는 진술도 함께 남깁니다. “확인”은 사용자의 확인이지 객관적 진실 판정이 아닙니다.
- **그림**: nodeId가 entityId 또는 assertionId를 참조합니다. 색·사진·좌표·사용자 표시명은 그림 문서에만 저장합니다. 직접 작성한 선은 sourceAssertionId가 없으며 근거가 생기지 않습니다.

재분석 시 배열 순번으로 편집을 재연결하지 않습니다. 동일 원본 버전·범위·역할에 대한 안정 식별자를 먼저 비교합니다. 범위가 바뀌면 일치 후보를 보여주고 확인 전에는 기존 그림을 보존합니다. 사라진 출처는 고아 항목으로 표시하며 자동 삭제하지 않습니다.

## 좌표·텍스트·포트

1. 영구 좌표는 월드 좌표의 유한 실수입니다. 화면 좌표 = (월드 좌표 - 카메라 원점) × zoom입니다. 포인터 역변환은 이 식의 역함수 한 곳에서 처리합니다. 확대·축소가 저장 좌표를 바꾸지 않습니다.
2. node.bounds는 실제 렌더링 폭·높이와 앵커를 가집니다. 그룹은 우선 한 단계만 허용하며 자식 좌표는 그룹 로컬 좌표로 관리합니다. 그룹 이동은 하나의 변환으로 적용하고 자식마다 별도 제한하지 않습니다.
3. 격자와 정렬은 사용자 동작 완료 때 적용합니다. 자동 저장·불러오기가 다시 반올림하지 않습니다. 잠긴 노드는 자동 정렬에서도 이동하지 않습니다.
4. Pretendard 로드 완료 뒤 Canvas measureText와 실제 줄 높이를 이용합니다. Intl.Segmenter로 grapheme 경계를 지켜 줄을 나눕니다. 텍스트 크기 변경은 노드 bounds·충돌 검사·SVG 내보내기에 같은 결과를 사용합니다. 긴 단일 토큰은 명시적 최대 폭에서 나누며 원문은 별도 접근 가능합니다.
5. 포트는 portId, nodeId, side, offset을 가집니다. 포트 간 최소 간격이 부족하면 다른 면 또는 노드 크기 확장 후보를 사용합니다. 클램핑으로 여러 연결을 동일 지점에 몰지 않습니다.
6. 라벨은 특정 경로 구간과 비율, 법선 오프셋을 기본 앵커로 가집니다. 사용자가 고정한 라벨만 절대 좌표를 사용합니다. 경로 재계산 후에도 의도한 행위선과의 연결이 보입니다.

## 선 배치: 제약을 먼저, 학습은 그다음

고정 노드·그룹·직접 지정 포트·금지 영역은 필수 제약입니다. 유효하지 않은 후보는 모델 점수가 높아도 선택하지 않습니다.

- 실제 노드 bounds를 여백 12px만큼 확장한 장애물로 만듭니다. 시작·종료 포트에서 바깥쪽으로 나오는 구간은 별도로 처리합니다.
- 장애물의 변과 포트 좌표로 직교 가시성 그래프를 만들고 A*로 경로를 찾습니다. 길이·꺾임·기존 선과의 교차·라벨 영역을 비용에 반영합니다. 동률은 안정 ID 순서로 결정합니다.
- 선 교차 최소화는 목적 함수이며 모든 그래프에서 교차 0을 보장하지 않습니다. 다른 노드 내부 통과는 허용하지 않습니다.
- 사용자가 지정한 꺾임점도 검증합니다. 불가능하면 마지막 유효 경로를 유지하고 수정할 구간을 표시합니다. 연결을 누락하거나 장애물을 몰래 통과시키지 않습니다.
- 사용자 고정 위치를 보존한 유효 배치만 기존 Ridge 랭커에 전달합니다. 현재 모델을 변경할 때는 기하 특징·학습 파일·브라우저 추론 패리티를 함께 갱신합니다.
- 구현 전 불규칙 노드 크기, 밀집 포트, 그룹 장애물 표본을 만듭니다. 자체 라우터가 유지하기 어려운 범위에 도달하면 포트·직교 라우팅을 지원하는 ELK를 같은 표본으로 비교한 뒤 도입 여부를 결정합니다. 이번 UI 변경에 의존성을 추가하지 않았습니다.

## 편집 동작과 저장

드래그 시작 시 기준 문서를 잡고 이동 중에는 임시 변환만 갱신합니다. pointerup에서 하나의 변경으로 기록하고 Escape/pointercancel은 되돌립니다. requestAnimationFrame으로 화면 갱신을 묶고 움직인 노드에 연결된 선부터 재계산합니다.

기존 동작을 moveNodes, moveGroup, updateLabel, reconnectManualEdge, resizeGroup 등 사용자 의도 단위로 기록합니다. 각 동작의 역변경을 보관해 다중 선택 이동을 한 번에 취소합니다. AI 정렬도 하나의 실행 취소 항목입니다. 키보드 이동과 수치 입력이 같은 변경 경로를 사용합니다.

기기 보관함의 관계도 문서는 revision과 IndexedDB 조건부 쓰기로 동시 수정을 감지합니다. 구버전의 서버 문서는 Blob 조건부 쓰기를 사용했습니다. 별도 편집 내용을 합치는 기능을 설계할 때도 기준 revision·동일 속성 충돌 검사를 유지합니다.

스키마 v2 도입 시 v1 원본을 보관하고 소유권 확인 후 순수 변환합니다. 노드·선·그룹 수, 사진 참조, 잠금 상태, 출처 참조를 변환 전후 대조합니다. 실패하면 v1을 그대로 읽고 무단으로 빈 문서를 저장하지 않습니다.

## AI 추출의 정밀도

관계 유형 분류와 행위자·대상·시간·부인 추출을 별도 평가합니다. 기존 E5·Kiwi·LoRA를 재사용하고 다음 오류를 먼저 데이터로 분류합니다.

| 평가 축 | 반드시 포함할 사례 | 보고할 지표 |
|---|---|---|
| 행위자·대상 | 능동/피동, 복수 인물, 조사 생략, 인용 속 발화자 | span F1, 역할별 정확 일치 |
| 신원 연결 | 동명이인, 별칭, 대명사, 서로 다른 원본 | 잘못된 병합률, 미해결 비율 |
| 부인·전언 | “때리지 않았다”, “맞았다고 들었다”, 상반 진술 | 상태별 정밀도·재현율 |
| 금액·시점 | 여러 금액, 취소된 송금, 예정/실제, 녹음일/사건일 | 대상·단위·시점 결합 일치 |
| 근거 | Unicode, OCR 수정본, 재전사 | quote/span 완전 일치, 버전 추적 |

실제 사례는 명시적 동의와 이용 권리를 확보한 비식별 자료만 별도 수집합니다. 사건·문서·화자 단위로 학습/검증/최종평가를 분리하고 문장 중복과 템플릿 누출을 제거합니다. 두 명의 라벨러와 불일치 검토를 거칩니다. 최종평가 자료를 임계값 조정에 재사용하지 않습니다.

분류 점수를 확률로 표현하려면 분리된 검증 집합에서 보정하고 신뢰도 구간을 보고합니다. 초기 제품 목표는 표시할 고신뢰 후보의 역할·부인 정밀도 95% 이상으로 설정하되 **아직 측정·달성하지 않은 목표**입니다. 임계값 아래는 보류하고 원문 확인을 요청합니다. 모르는 인물·모호한 조사·근거 밖 내용은 추측해 채우지 않습니다.

법령·판례 후보 검색은 진술 추출 뒤에 연결합니다. 현재 인덱스는 법령 11종·판례 7건에서 추출한 2,603개 구간입니다. 원문과 참고할 질문을 제공하며 사건 당시 시행 조문과 적용 요건은 따로 검토해야 합니다.
